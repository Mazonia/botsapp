Outsourcing & Developer Integration Guide

BotsApp provides a 100% standard REST API and drop-in SDK so contractors, freelancers, or backend devs can easily integrate it with any system.

| | |
curl -X POST http://localhost:3001/api/send \ -H "Content-Type: application/json" \ -d '{"phone": "233241234567", "message": "Hello from API!"}'
// Drop-in Laravel Client use App\Services\BotsAppClient; $client = new BotsAppClient(); $response = $client->sendMessage('233241234567', 'Hello from Laravel!'); // Send Rich Media $client->sendMedia('233241234567', '/path/to/invoice.pdf', 'Your invoice');
const axios = require('axios'); const res = await axios.post('http://localhost:3001/api/send', { phone: '233241234567', message: 'Hello from Node.js!' }); console.log(res.data);
import requests res = requests.post('http://localhost:3001/api/send', json={ 'phone': '233241234567', 'message': 'Hello from Python!' }) print(res.json())
